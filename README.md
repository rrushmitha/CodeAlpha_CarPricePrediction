
# Car Price Prediction

## Objective
To predict used car prices using machine learning techniques.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Exploratory Data Analysis
- Correlation Heatmap
- Present Price vs Selling Price
- Fuel Type vs Selling Price
- Year vs Selling Price

## Model Used
Random Forest Regressor

## Results
- R² Score: 96.44%
- MAE: 0.597

## Conclusion
The Random Forest model successfully predicted used car prices with high accuracy and strong predictive performance.
